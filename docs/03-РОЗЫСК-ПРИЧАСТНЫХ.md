# Розыск причастных: волонтёры, шаблоны, журналирование

## Цель модуля
Найти живых родственников, земляков, однополчан, сокурсников, однофамильцев
захороненных в Корпечи через Одноклассники (группы землячеств, поисковые
отряды, доски памяти) и зафиксировать все контакты для:
1. Предотвращения дублирования (один адрес — один волонтёр).
2. Предоставления корректных шаблонов писем.
3. Подготовки петиции с доказательной базой.

## Архитектура
- **mem-OK** (github.com/annachurasheva/mem-OK) — очередь адресов, шаблоны,
  журналирование контактов.
- **mem-ok-s-admin** (github.com/annachurasheva/mem-ok-s-admin) — админка
  для волонтёров-координаторов: распределение задач, проверка шаблонов,
  экспорт отчётности.

## Процесс розыска (шаги)

### 1. Формирование очереди адресов
Из карточек fallen извлекаются поля:
- `conscription_location` (место призыва → землячество)
- `place_birth` (место рождения → родственники)
- `warunit` (воинская часть → однополчане)

Адреса группируются по регионам и типам (земляки / родственники / сослуживцы).

### 2. Назначение волонтёра
Координатор (через mem-ok-s-admin) назначает волонтёра на конкретный адрес.
Система проверяет: адрес уже в работе? → если да, отказать; если нет,
назначить и зафиксировать.

### 3. Предоставление шаблона
Волонтёр получает готовый шаблон письма с:
- Реквизитами проекта (Anna-Ch, контакты, ссылка на мемориал)
- Данными павшего (ФИО, дата гибели, источник ЦАМО)
- Целью обращения (уточнение родственных связей / запрос документов /
  приглашение к петиции)

Шаблоны хранятся в `mem-OK` и версионируются.

### 4. Журналирование контакта
После отправки письма волонтёр вносит в систему:
- Дата отправки
- Кому отправлено (адрес, канал связи)
- Результат (ответ получен / игнор / отказ / подтверждение родства)
- Следующий шаг (повторить через месяц / передать координатору / закрыть)

Все записи хранятся в журнале `contacts.log` (или базе данных модуля).

### 5. Подготовка петиции
Из журнала извлекаются:
- Список подтверждённых родственников (с документами)
- Список откликов землячеств (с письмами поддержки)
- Статистика розыска (отправлено X, откликнулось Y, подтверждено Z)

Эти данные входят в пакет для петиции: «Просим провести работы согласно
регламентам верификации с докум. ЦАМО».

## Правила
- Один адрес = один волонтёр (дублирование запрещено).
- Все письма — от имени проекта, с реквизитами и ссылками.
- Журналирование обязательно: без записи контакт не засчитывается.
- Шаблоны утверждаются координатором до рассылки.

## Правовая чистота
- Волонтёры действуют по доверенности от владельца проекта (Anna-Ch).
- Все шаблоны проходят юридическую ревизию (соответствие ФЗ-152,
  Постановлению №2228, правилам переписки с госорганами).
- Журнал контактов — доказательство системности работы (для грантодателей,
  уполномоченных органов, подрядчиков).
